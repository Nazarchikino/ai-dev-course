# grade-report — відомість успішності групи

Практична робота № 9 «Рефакторинг коду за участю AI».

Модуль `src/report.js` формує текстову відомість успішності. Код працює, але його важко
читати й змінювати. Тестів немає. Вимог, крім самого коду, теж немає: **поточна поведінка
і є специфікацією**.

## Команди

```
npm install
npm run report                 # відомість для tests/fixtures/group.json
node src/cli.js tests/fixtures/group.json --short
npm run lint                   # метрики структури (ESLint)
npm test                       # тести (спершу їх треба написати)
npm run coverage               # покриття
```

## Правило роботи

Рефакторинг не змінює поведінку. Якщо ви помітили дивну поведінку (можливу помилку),
**не виправляйте її під час рефакторингу**: запишіть у звіт і винесіть в окрему задачу.
