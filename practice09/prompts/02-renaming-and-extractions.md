# Завдання 3–4. Перейменування змінних та поетапне виділення функцій

## Завдання 3. Запит на змістовні імена змінних
```text
Запропонуй змістовні імена для змінних r, arr2, sum2, cnt2, t, d, g, ga, s у [# src/report.js].
Запропонуй імена та поясни кожне. Код не переписуй.
```

### Таблиця перейменування змінних (F2 у VS Code + заміна `var` на `const`/`let`)
| Старе ім'я | Нове ім'я | Оголошення | Пояснення призначення |
|---|---|---|---|
| `r` | `reportText` | `let` | Накопичуваний багаторядковий текст відомості успішності |
| `arr2` | `attentionStudents` | `const` | Масив імен студентів, які потребують уваги (`studentAverage < 2.5`) |
| `sum2` | `groupGradesSum` | `let` | Сума середніх балів студентів для розрахунку середнього бала групи |
| `cnt2` | `studentCount` | `let` | Кількість врахованих студентів групи |
| `s` | `student` | `const` | Поточний об'єкт студента `{ name, grades }` у циклі |
| `t` | `gradesSum` | `let` | Сума оцінок поточного студента |
| `d` | `studentAverage` | `let` / `const` | Середній бал поточного студента |
| `g` | `studentLevel` | `let` / `const` | Словесна назва рівня успішності студента |
| `avg` | `groupAverage` | `let` / `const` | Середній бал групи |
| `ga` | `groupLevel` | `let` / `const` | Словесна назва рівня успішності групи |

## Завдання 4. Поетапні запити на виділення функцій
Використано шаблон із методичних вказівок:
```text
Виділи з buildReport у [# src/report.js] окрему функцію, що [опис фрагмента].
Обмеження: поведінка не змінюється; решту коду не чіпай; нових залежностей не додавай.
Формат: спочатку перелічи ВСІ внесені зміни списком, потім наведи код.
```

Виділені функції (кожна — окремим комітом після успішного `npm test`):
1. `average(values)` — обчислення середнього арифметичного масиву оцінок (`0` для порожнього масиву).
2. `gradeName(score)` — визначення словесної назви рівня за середнім балом (`"відмінно"`, `"добре"`, `"задовільно"`, `"незадовільно"`).
3. `formatScore(score)` — форматування бала до 1 знака після коми разом із назвою рівня у дужках (`4.8 (відмінно)`).
4. `formatStudentName(name, isShort)` — форматування ПІБ студента у повному (`Коваль Андрій`) або скороченому (`Коваль А.`) вигляді.
5. `formatStudentLine(student, studentAverage, opts)` — формування повного рядка студента у відомості включно з позначкою `[!]` при `studentAverage < 2.5`.
