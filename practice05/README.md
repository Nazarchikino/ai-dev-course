# event-registration — стартовий проєкт до практичної роботи № 5

Проєкт продовжує практичну роботу № 4: функції `registerParticipant` і `cancelRegistration` уже реалізовано (якщо ви завершили ПР4, можете працювати зі своїм кодом, додавши каталоги `test/` і `prompts/` з цього архіву).

- `prompts/templates.md` — ваша колекція шаблонів (заповнюєте на занятті 14).
- `.github/prompts/` — файли багаторазових запитів (створюєте на занятті 15).
- Нові тести: `test/seats.test.js` (функція `availableSeats` у `src/seats.js`) і `test/validate.test.js` (функція `validateParticipant` у `src/validation.js`).
- Запуск: `npm test` (Node.js 20+). Файли в `test/` не змінювати.
