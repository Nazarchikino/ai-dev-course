# college-tools — стартовий проєкт до практичної роботи № 3

- `src/legacy/` — «незнайомий» код для пояснення (частина 1). Не змінюйте його.
- `examples/run-legacy.js` — приклади для перевірки пояснень: `npm run examples`.
- `src/buggy/` — шість модулів із помилками (частина 2).
- `test/` — тести; запуск одного тесту: `node --test test/bug1-averages.test.js`, усіх: `npm test`.

Файли в каталозі `test/` не змінюйте. Потрібен Node.js 20 або новіший.
