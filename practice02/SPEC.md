# Вимоги до функцій практичної роботи № 2

Структура даних здобувача — у файлі `src/models.js`, приклад даних — `data/students.json`.
Перевірка: `npm test` (вбудований засіб `node --test`, встановлювати нічого не потрібно).

## src/text.js

### longestWord(text)
- Повертає найдовше слово рядка. Словом вважається послідовність літер або цифр (зокрема українських).
- Якщо кілька слів однакової довжини — повертає перше з них.
- Для порожнього рядка або рядка без слів повертає `""`.

## src/students.js

### uniqueEmails(students)
- Повертає масив унікальних адрес електронної пошти, приведених до нижнього регістру, без пробілів на початку й у кінці.
- Порожні адреси ігноруються. Порядок — за першою появою.

### calculateAverageGrade(scores)
- Повертає середнє арифметичне балів, округлене до одного знака після коми.
- Для порожнього масиву повертає `0`.

### formatStudentName(fullName)
- «Петренко Андрій Іванович» → «Петренко А. І.»; «Шевчук Олег» → «Шевчук О.».
- Зайві пробіли ігноруються.

### groupAverage(students, groupCode)
- Повертає середнє **всіх балів** здобувачів указаної групи, округлене до одного знака.
- Якщо в групі немає здобувачів або балів — повертає `null`.

## src/study-group.js

### class StudyGroup
- `new StudyGroup(code, year)` — шифр групи та рік вступу; властивість `students` — порожній масив.
- `addStudent(student)` — додає здобувача; кидає `Error`, якщо `groupCode` здобувача не збігається з шифром групи або здобувач із таким `id` уже доданий.
- `averageScore()` — середнє всіх балів групи (правила як у `calculateAverageGrade`).
- `topStudents(n)` — `n` здобувачів із найвищим середнім балом; за однакового середнього — за `fullName` в алфавітному порядку.
- Інших публічних методів клас не містить.
