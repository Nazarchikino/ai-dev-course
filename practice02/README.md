# study-group — стартовий проєкт до практичної роботи № 2

1. Прочитайте `SPEC.md` і `src/models.js`.
2. Створюйте файли `src/text.js`, `src/students.js`, `src/study-group.js` за методичними вказівками.
3. Перевіряйте себе командою `npm test` (потрібен Node.js 20 або новіший; встановлювати залежності не потрібно).

Файли в каталозі `test/` не змінюйте.
